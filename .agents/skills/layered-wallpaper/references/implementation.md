# 从整图到可延伸场景

## 素材契约

每项素材记录：用途、透明边界、原始尺寸、取样区域、根部/轮轴/烟囱锚点、统一缩放、调色允许范围、重复方式、反射方式、来源路径和哈希。素材与元数据一起保存。

山体要有完整山脊与能接地的树根。树冠图集的每个区域都应有完整不同的枝干结构、透明留白，不能切断叶片后靠邻片补齐。草岸内侧必须连续，不可按颜色剔除内部阴影造成破洞；水沿透明只处理边界。列车不能带原图背景或烘焙烟带；湖面不能留下重复反射的原图内容。

先独立检查 alpha、边界和接地，再看合成。全景好看不能证明素材单独可用。

## 世界与缓存

世界元素位置由 `worldCell × span − camera × depth + offset` 一类规则求出。随机量只由稳定的 cell、salt、seed 决定。时间控制微动，不能决定本应固定的地形。

完整山体使用等比变换；自然疏密用不同山群/树冠和间距构成，不能逐列平移纹理做“不同山形”。可见单元枚举包含最大枝冠/山群宽度和保护区；画外回收不应改变画内的对象。

缓存须明确依赖：素材颜色缓存由素材与调色参数决定；岸线接触由相机/种子/小山位置与可见性决定；水、烟、风还依赖时钟。缓存有效范围外不能复用旧画面，隐藏后要清空接触图与反射源。无损优化优先考虑静态预处理、准确失效、复用已有缓冲、避免重复上传和分配。

## 山脚、岸线与水

轨前山保持核心不透明，以真实绘制变换写入接触纹理。Shader 在局部山脚带读取实际颜色/覆盖度，用世界噪声与高度混合草地和根部色块；接触阴影让山从岸边长出。不要平移山脊、改变整座山的 alpha 或把平滑几何形状盖在树根上。

草岸与水共用同一轮廓/遮罩，否则会有直线边、漏水或双重边缘。水面由选择过的反射源生成，再做细波、近处柔化和零散高光；山脚融合后的颜色也要进入相应局部反射。波光要让倒影有水感，不是把整个湖面做成毛玻璃。

## 动静与方向

镜头跟车 → 屏幕上的车几乎不横移；世界相反经过 → 近景快、远景慢。车头朝行进方向 → 整列车、烟囱与烟尾符号一同换向。反射共享对象姿态和时间。

速度零不等于暂停：前者可只停止旅行，烟、水与风继续；后者停止时钟与绘制。恢复时丢弃隐藏期间墙钟差，避免突然跳位置。关闭风应冻结当前风相位，不把云退回起点。地形种子与云种子分离，换云不改变地形。

## 本项目已经踩过的坑

- 整图横条裁切：一旦左右延伸就露出旧构图的边缘与缺失区域。
- 单一枝叶反复缩放：轮廓仍然重复；需增加真正不同拓扑，结合群落与空隙。
- 用固定宽度和独立高度铺山脚树丛：会把叶片、树冠压扁；完整树丛保持原始宽高比，疏密用位置与等比大小控制，检查实际绘制变换而不只检查素材文件。
- 岸线周期拼图：重复轮廓明显且水沿太水平；改为世界坐标结构场，原画只作笔触。
- 透明山脚：桥/火车透出；应混合颜色和材质，保留实体遮挡。
- 全上半屏翻转：不想反射的远山也进湖，且会重复画面；用显式源。
- 独立山坡与树带速度：行进后脱节；共享 world cell 与相位。
- 山形“随机”依赖时间：往返无法复现，暂停换向突然跳变。
- 自动质量降低：帧数好看但效果变化，不能用于本用户要求的无损性能验收。
