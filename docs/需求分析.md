# 星河夜行列车 · 需求分析

## 1. 背景

用户希望基于开源单文件 WebGL 动画「落日云间列车（sunset-cloud-train）」改编一版「星河版本」：把原版的晚霞云海换成星空夜景，列车始终向前行驶。成品是一段可以调参的观赏动画，不是游戏。

### 1.1 原版来源（已找到）

| 项 | 内容 |
| --- | --- |
| 仓库 | https://github.com/incarnation-gem/sunset-cloud-train |
| 抓取版本 | commit `c00934d482b07ef5b6f84dcbac73e17b777f0a86`（仓库只有 `README.md` 与 `index.html`） |
| 本地副本 | `reference/sunset-cloud-train.html`（原样下载，未改动） |
| 上游 | 提取自 Rice-dog/code-codex v0.2.15 的「Cloud Train Background」插件（commit `0902983a`），https://github.com/Rice-dog/code-codex ，MIT 许可 |
| 原始 shader | 作者 mdb。源项目注明 "No redistribution license was supplied." |
| 原作者声明 | 对 code-codex 代码的引用和修改遵循 MIT；mdb 的 shader 未附再分发许可，仅供学习与欣赏，不建议商用；权利人认为不妥会下架 |
| 仓库许可文件 | sunset-cloud-train 仓库没有 LICENSE 文件，许可说明只写在 README 里 |

### 1.2 原版能力摘要

- 零依赖单文件 HTML，WebGL 2，一个场景 shader 加一个后期 shader，带帧间拖影反馈。
- 13 层高度场云（每层 8 阶 fbm）、日落配色、悬索桥、小火车和蒸汽，全部在 shader 里绘制。
- 右下角设置面板：14 项滑杆参数（开场时长、开场羽化、行进速度、视角缩放、垂直位置、云层起伏、噪声细节、曝光、饱和度、色相、色温、渲染比例、帧间拖影、暗角）、3 项染色（天空、烟雾、列车）、单项重置、一键重置、记住设置（localStorage）、重播。
- 渲染比例默认 0.75，devicePixelRatio 上限 1.5，页面隐藏时停帧。

## 2. 目标

1. 产出单文件 `index.html`：纯前端，离线可用，Chrome / Edge 双击即可运行，不依赖 CDN 和网络。
2. 画面贴近参考图：深蓝紫星空、粉紫积云、多孔石拱桥、蒸汽机车拉着暖黄车窗车厢、镜面水面倒影、两侧树影和电线杆、远处暖色灯光，二次元/像素插画风。
3. 列车持续向前，无缝循环，不出现跳变。
4. 没有独立显卡的电脑上也能流畅运行。

## 3. 功能需求

### 3.1 画面元素

| 编号 | 元素 | 要求 |
| --- | --- | --- |
| F1 | 星空 | 天顶深蓝到地平线紫的渐变；大量小星星随机闪烁；少量带十字光芒的亮星 |
| F2 | 银河 / 星云 | 斜向的淡紫蓝光带，带噪声纹理和暗尘带，亮度可调 |
| F3 | 流星 | 偶发流星从右上划向左下，带渐隐拖尾，频率可调，可设为 0 关闭 |
| F4 | 云团 | 底层算法与原版 sunset-cloud-train 一致：移植原版的噪声、fbm 和 12 层深度高度场与色带合成，晚霞配色换成星河版的云颜色（云亮部、云顶、云暗部）；多层视差随列车前行；云量、云层高度、云层起伏可调 |
| F4a | 云团增强 | 在原版算法之上向「治愈星空列车」海报靠拢，具体如下：<br>- 层次：前后层叠关系清楚；每团云顶缘有粉色亮边、底部和内部渐暗成深紫；远层更暗并融进夜色，近层更亮更饱和；不出现大块平涂的单色云。<br>- 边缘：圆润的鼓包轮廓，减少高频锯齿和孤立像素，边缘约 1～2 像素抗锯齿；像素风下保持像素块，但边缘不碎。<br>- 可调：云边圆润、云体积感、远近层次三项，设为 0 时对应改动关闭。<br>- 性能：SwiftShader 下的稳态帧率不低于增强前（约 21 fps） |
| F5 | 远岸与灯光 | 地平线上低矮的远岸剪影，成簇的暖色灯点和光晕 |
| F6 | 石拱桥 | 多孔半圆拱，拱圈石块、桥面檐口亮边、护栏立柱；随行驶横向滚动 |
| F7 | 列车 | 蒸汽机车（烟囱、汽包、驾驶室、煤水车、排障器、大动轮和连杆、车头灯光束），后挂若干客车厢，暖黄车窗加光晕；车厢数可调 |
| F8 | 蒸汽 | 从烟囱冒出，向后上方飘散成团，停留在空气中（相对地面静止），浓度可调 |
| F9 | 水面 | 地平线以下镜面倒影，倒映星空、云、桥、列车、灯光；轻微波纹扰动和水面高光条纹 |
| F10 | 近景 | 岸边树丛剪影、电线杆与电线，比桥滚动略快，形成前景视差 |

### 3.2 运动

| 编号 | 要求 |
| --- | --- |
| M1 | 默认「镜头跟随」：列车停在画面中偏右位置，桥、近景、云、远岸按各自视差向左滚动，表现一直前行 |
| M2 | 可切换为「列车穿行」：镜头固定，列车从左侧驶入、右侧驶出后从左侧再次进入 |
| M3 | 所有滚动量按周期取模，长时间运行不出现浮点精度问题和接缝跳变 |
| M4 | 支持暂停；系统开启「减少动态效果」时默认放慢 |
| M5 | 镜头远近与镜头高度（对应原版的「视角缩放」「垂直位置」）：以屏幕中心缩放、整体上下平移；所有图层统一变换，倒影与实体对齐，缩小时画面边缘也有内容，列车跟随与穿行按可见范围计算 |
| M6 | 默认镜头取视频成片的最终构图：镜头远近 0.5、镜头高度 0.06。只为保证录制画质的设置（渲染比例 1、关闭自动降画质）不作为默认值。存储键升级为 `v2`，让新默认值对所有用户生效 |

### 3.3 参数面板

保留原版面板思路：右下角可折叠面板、分组、每项单独重置、一键恢复默认、记住设置。画面参数不少于 14 项，并提供颜色项。默认值对应参考图配色。

| 分组 | 参数 |
| --- | --- |
| 运动 | 行进速度、镜头跟随、暂停 |
| 镜头 | 镜头远近、镜头高度 |
| 夜空 | 星星密度、闪烁强度、银河亮度、流星频率 |
| 云与蒸汽 | 云量、云层高度、云层起伏（同原版 amplitude）、云边圆润、云体积感、远近层次、蒸汽浓度 |
| 列车 | 车厢数量、车窗亮度、光晕强度 |
| 水面 | 地平线高度、倒影亮度、波纹强度 |
| 后期 | 曝光、饱和度、暗角、色阶（像素化分色） |
| 画质 | 渲染比例、像素风（最近邻放大）、噪声细节、帧率上限、自动降画质 |
| 颜色 | 天顶、地平线、云亮部、云顶、云暗部、车窗、车身、桥体、远处灯光、近景剪影 |

### 3.4 兼容与降级

- 优先 WebGL 1（集显和软件渲染器支持面最广）。
- WebGL 不可用：显示友好提示，并用 Canvas2D 画一个简化版（渐变星空、拱桥、带车窗的列车循环行驶）。
- WebGL 上下文丢失：提示并在恢复后重建。

## 4. 非功能需求

| 编号 | 要求 |
| --- | --- |
| N1 | 性能：默认画质下集显 1080p 屏幕可达 60 帧；可降到渲染比例 0.25、噪声 1 阶、帧率 20 |
| N2 | devicePixelRatio 上限 1.5，渲染分辨率 = CSS 尺寸 × min(dpr, 1.5) × 渲染比例 |
| N3 | 页面不可见时停止 requestAnimationFrame |
| N4 | 自动降画质：持续掉帧时逐步降低渲染比例，并同步到面板 |
| N5 | 单文件，无外部请求；控制台无报错 |
| N6 | 设置存 localStorage，存储不可用时静默回退默认值 |

## 5. 约束

- 云的生成算法移植自 mdb 的原始 shader（无再分发许可）。用户已知悉并接受：`index.html` 仅供本地学习欣赏，不公开发布、不商用；来源和「无再分发许可，仅本地学习使用」要在 `index.html` 顶部注释和设计文档中如实标注。除云以外的 shader 从零编写；面板交互、渲染循环结构和参数思路借鉴原版（这部分属 code-codex，MIT）。
- 继承原作者声明：仅供学习欣赏，不建议商用。
- 除本文档和设计文档外不新增其他文档。

## 6. 验收标准

1. Chrome / Edge 以 `file:///` 打开 `index.html`，控制台无报错。
2. 画面包含 F1～F10 的全部元素，配色接近参考图。
3. 间隔截图对比，桥和近景位置变化，列车始终在画面中前行。
4. 面板可折叠，所有参数实时生效，重置和记住设置可用。
5. 渲染比例、帧率上限、自动降画质可用；切换标签页后停帧。

## 7. 视频导出

### 7.1 背景

用户希望把动画做成一段唯美的合成视频：镜头拉到最远，录制星河列车画面，配上音乐《Letter from the Clouds》（mp3，48 kHz 立体声，233.32 秒，320 kbps），再加上后期合成效果。

### 7.2 功能需求

| 编号 | 要求 |
| --- | --- |
| V1 | 画面用 `index.html` 本身渲染（新版云），不做实时屏幕录制；逐帧确定性渲染，不掉帧、不卡顿 |
| V2 | 1920×1080、30 fps，全分辨率渲染（渲染比例 1，关闭自动降画质），隐藏面板、标题和帧率显示 |
| V3 | 镜头：开场约 14 秒内从远近 1 平滑拉到最远 0.5，之后保持；镜头高度可按构图微调；全程镜头跟随，列车持续前行（成片的最终构图后来成为页面默认镜头，见 M6） |
| V4 | 时长与音乐一致 |
| V5 | 合成效果：开头黑场淡入、结尾淡出；克制的柔光泛光、轻微暗角、细微胶片颗粒；开场叠加淡入淡出的标题「星河夜行列车」和副标题「Letter from the Clouds」，字体细、留白、白色半透明带柔和阴影；结尾淡入一行小字 |
| V6 | 音频淡入 2 秒、淡出 5 秒，AAC 320 kbps |
| V7 | 视频 H.264、yuv420p、faststart，通用播放器可直接播放 |
| V8 | 录制、合成都用项目内脚本完成，可重复执行；视频等产物不入库 |

### 7.3 约束

- 只用本机已有工具：Edge（无头模式 + DevTools 协议）、Node、ffmpeg，不新增 npm 依赖。
- 脚本放 `tools/`，产物放 `export/`，`export/` 加入 `.gitignore`。
- 音乐和成片仅供个人欣赏，不公开发布（同第 5 节的许可约束）。

### 7.4 验收标准

1. 成片 1920×1080、30 fps，含一条 H.264 视频流和一条 AAC 音频流，时长与音乐一致（误差小于 0.1 秒）。
2. 抽帧检查：片头标题清晰、不压画面主体；拉远过程平滑；中段列车在行驶；片尾淡出到黑。
3. 先出 10 秒左右样片确认效果，再渲染全片。
