# 蓝天湖景列车 · 设计文档

> 蓝天主题对照参考图做模块化逼近；正式 SVG 壁纸入口与 lab TA 双轨并行。星河主题是纯 WebGL 成品，本文档对齐其 docs 结构，但工作方式不同——见第 2 节与第 9 节。

## 1. 背景与双轨

蓝天湖景列车面向 Wallpaper Engine / 浏览器观赏壁纸（非游戏）。视觉目标是吉卜力 / 新海诚气质的**湖景远眺**：天空与大积云占大半画面，列车很小停在石桥上，湖面近镜面，岸线是亮绿薄草带，近景只做两侧框景灌木，不抢戏。

### 1.1 双轨说明

| 轨道 | 路径 | 职责 |
| --- | --- | --- |
| 正式 SVG 壁纸入口 | `themes/blue-sky-train/index.html`（`wallpaper.js` + `assets/blue-sky-train/vector/`） | 当前用户可预览 / 打包的正式主题；**未切换前保持原样** |
| lab TA | `themes/blue-sky-train/lab/`（`cloud-library.html`、`examples/`、`src/`） | 对照参考图推进美术与程序；**正式入口未切换前，美术推进只在 lab** |

正式入口切换到 lab 渲染路径，须用户明确确认后再做。在此之前：

- 不把 lab 的 GLSL / 素材改动接入 `index.html`
- 不把「参考图级」验收标准套到正式 SVG 入口

### 1.2 当前主实验入口

- 全场景整合：`lab/cloud-library.html`（由 `npm run build:cloud-library` 生成）
- 早期单模块样片：`lab/examples/cloud.html` / `train.html` / `water.html` / `scene.html`
- 方案页：`lab/index.html`

## 2. 工作方法（必须遵守）

> **醒目约定（用户明确要求）**  
> **每个模块先单独实现效果，再整合一版对照参考图看。**  
> 禁止：未单模块验收就大改全场景。

### 2.1 单模块

每个视觉模块必须先有**独立预览**，任选其一即可：

1. 现有 `lab/examples/*.html`（云 / 列车 / 水面 / 组合样片）
2. `cloud-library.html` 查看菜单里的单模块 mode（如「只看连续云场」「单看近景草叶」「列车与原版烟雾」「完整云塔 A」等）
3. 必要时新建 lab 单模块页（仍只改 lab，不改正式 SVG）

### 2.2 验收

- 单模块对照参考图（及用户目标气质图）达标后，才允许进入整合
- 「达标」以用户确认为准，不以单次截图自嗨通过

### 2.3 整合

- 整合入口固定为 `cloud-library.html` 全场景一版
- 与参考图**并排对照**：原图 2048×768，以及用户目标气质图
- 整合轮次只做「对照后的收束与冲突消解」，不做未经验收模块的大改

### 2.4 禁止

| 禁止 | 说明 |
| --- | --- |
| 未单模块验收就大改全场景 | 例如直接在全场景里同时改云、岸线、近景、桥 |
| 用全场景「看起来差不多」代替单模块验收 | 全场景容易互相遮挡，掩盖模块问题 |
| 正式入口未切换前改 SVG 画面当主战场 | 美术推进只在 lab |

## 3. 参考目标

### 3.1 气质

吉卜力 / 新海诚式湖景远眺——空气通透、天空主导、主体很小、近景克制。

### 3.2 构图要点

| 要素 | 目标 |
| --- | --- |
| 天空与大积云 | 占画面大半；云是主角之一，不是填缝 |
| 列车 | 很小，在石桥上；隔湖远眺感（R05 已校准车宽约 15% 画幅） |
| 湖面 | 近镜面；倒影清楚但不抢戏 |
| 岸线 | **亮绿薄草带**，衔接桥墩与水面；**不是** R09 式大块草丛贴片 |
| 近景 | 只做两侧**框景**灌木 / 枝叶；可有风摆，但形态不可大块抢戏 |

### 3.3 对照材料

- 原图像素：2048×768（`cloud-library` / `cloud-compare` 内嵌对照）
- 用户目标气质图：与原图并排，用于「气质」而非逐像素复刻

## 4. 模块清单

每项含：目标效果、源码文件、单独预览入口、当前状态、与参考差距、下一验收标准。

### 4.1 构图 / 镜头尺度

| 项 | 内容 |
| --- | --- |
| 目标效果 | 隔湖远眺：列车小、桥面与水线位置稳定，天空留白充足 |
| 源码文件 | `lab/src/scene-common.glsl`（`TRAIN_SCALE` / `HORIZON` / `DECK` / `BRIDGE_FOOT`） |
| 单独预览入口 | `lab/cloud-library.html` 全景 + 桥面/水线/列车标尺；早期 `lab/examples/scene.html` |
| 当前状态 | R05 已写入：`TRAIN_SCALE=vec2(.55,.43)`，`HORIZON=.265`，`DECK=.376`，`BRIDGE_FOOT=.294`（图高为单位；对应桥面约自上 62.4%、水线约自上 73.5%） |

| 下一验收标准 | 与原图并排时列车占比、桥面/水线位置无明显漂移；用户确认远眺感 |

## 6. 命令与预览路径

在项目根目录 `train-wallpapers/` 执行：

| 命令 | 作用 |
| --- | --- |
| `npm run build:cloud-library` | 构建 lab 云库全场景独立 HTML（素材与代码内嵌） |
| `npm run test:cloud-library` | 浏览器验证透明边缘、续接、确定性、调速等 |
| `npm run build:ta` | 构建早期 TA 方案与 `examples/` 单模块页 |
| `npm run test:ta` | 早期 TA 浏览器检查 |
| `npm start`（或 `npm run dev`） | 本地静态服务（`tools/serve.mjs`） |

预览路径（服务启动后）：

- 正式 SVG 入口：`/themes/blue-sky-train/index.html?controls=1`
- lab 全场景：`/themes/blue-sky-train/lab/cloud-library.html`
- lab 方案：`/themes/blue-sky-train/lab/index.html`
- 单模块样片：`/themes/blue-sky-train/lab/examples/` 下各 HTML
- 云像素对比（历史）：`/themes/blue-sky-train/lab/cloud-compare.html`

打包正式主题：`npm run build:blue-sky` → `dist/blue-sky-train/`。

## 9. 验收总流程（与需求分析一致）

1. **单模块**：独立预览对照参考图 → 用户确认  
2. **整合**：`cloud-library.html` 全场景并排对照 → 用户确认  
3. **正式切换**（另议）：仅当用户明确要求时，才考虑把 lab 成果接入正式 SVG / 新渲染入口
