# 蓝天湖景列车 · 需求分析

> 与 [设计文档](./设计文档.md) 配套。产品是观赏壁纸，不是游戏。工作方法：**每个模块先单独实现效果，再整合一版对照参考图看。**

## 1. 产品目标

| 项 | 说明 |
| --- | --- |
| 产品形态 | Wallpaper Engine / 浏览器可运行的动态观赏壁纸 |
| 主题 | 蓝天湖景列车（`themes/blue-sky-train/`） |
| 画幅 | 原画参考 8:3；对照常用 2048×768 |
| 非游戏 | 无关卡、无胜负、无操作关卡；可调参观赏即可 |
| 双轨 | 正式 SVG 入口继续可用；美术逼近在 lab TA 完成后再议切换 |

### 1.1 视觉总目标

吉卜力 / 新海诚气质的湖景远眺：

- 天空与大积云占大半
- 列车很小，在石桥上
- 湖面近镜面
- 岸线为亮绿**薄**草带
- 近景仅为两侧框景，不抢戏

## 2. 视觉需求表（按模块）

| 编号 | 模块 | 需求 |
| --- | --- | --- |
| V1 | 构图 / 镜头尺度 | 隔湖远眺稳定；`TRAIN_SCALE` / `HORIZON` / `DECK` 与原图标尺一致感；列车约占画幅宽度 15% 量级（以 R05 记载为准） |
| V2 | 天空与大气 | 通透蓝天；轻微空气透视；不脏、不抢云 |
| V3 | 云 | 大积云主导；完整素材轮廓与透明边；远近视差与续接；避免过密填满天空 |
| V4 | 远山与远岸 | 低对比偏蓝层次；轮廓与原图气质接近（可简化笔触） |
| V5 | 岸线薄草 | 亮绿细带贴水线；**禁止**用 R09 大块草丛贴片代替岸线 |
| V6 | 石桥 | 蓝灰结构可读；冷暖与石帽遮光正确；2048×768 下栏杆不丢 |
| V7 | 列车与蒸汽 | 小车可读；蒸汽为星河原版连续翻卷风格（R10），倒影同步 |
| V8 | 水面倒影 | 近镜面；同一场景求值；波纹可关且对齐 |
| V9 | 近景框景 / 风摆 | 两侧框景；风摆可有；**体量克制**，不遮挡主体叙事 |
| V10 | 日光分层 | `uSun` 手绘冷暖分层可读；与参考气质一致 |

## 3. 功能与工程需求（lab）

| 编号 | 需求 |
| --- | --- |
| F1 | `cloud-library.html` 作为全场景整合与对照入口 |
| F2 | 关键模块具备独立预览（examples、cloud-library mode、或新建 lab 页） |
| F3 | `npm run build:cloud-library` / `test:cloud-library` 可复现构建与检查 |
| F4 | 正式 SVG 入口（`index.html`）在用户未要求切换前保持可用、不被 lab 大改绑定 |
| F5 | 支持暂停、调速、日光滑杆等便于同帧对照的调试控件（以现有 lab UI 为准） |

## 4. 非目标

| 编号 | 非目标 |
| --- | --- |
| N1 | **暂不**切换正式 SVG 壁纸入口到 lab WebGL |
| N2 | **不**追求参考图逐像素复刻 |
| N3 | **不**把本主题做成可玩的列车游戏 |
| N4 | **不**在未单模块验收时大改全场景 |
| N5 | **不**修改星河主题文档或星河成品逻辑（蒸汽复用除外，且仅在蓝天 lab 内适配） |
| N6 | 本轮文档任务**不**改 GLSL/JS 画面代码、**不** rebuild cloud-library |

## 5. 验收流程

```
单模块独立预览 ──对照参考图 / 气质图──► 用户确认
        │
        ▼
cloud-library 全场景整合 ──并排对照──► 用户确认
        │
        ▼
（另议）正式入口切换或发布打包
```

细则见设计文档第 2 节与第 9 节。

## 6. 约束与已知限制（来自既有 handoff，不编造）
