# 蓝天湖景列车

入口：本地服务的 `/themes/blue-sky-train/index.html?controls=1`。

`index.html` 提前注册宿主回调；`settings.js` 统一参数规则；`wallpaper.js` 加载矢量场景并管理播放、存储和宿主暂停；`style.css` 管理画幅和控制面板。实际画面放在 `../../assets/blue-sky-train/vector/`。

运行时由一个帧率受控的时钟驱动 SVG 动画。水面通过局部裁切和位移滤镜形成轻波，蒸汽沿固定路径缓缓上升。背景、桥、列车和云的主体保持原构图。静态 SVG 不含任何动画，适合继续编辑或设计使用。

默认铺满屏幕；原画幅为 8:3，较窄屏幕会裁去左右区域，可切换为「完整画面」。浏览器设置保存在该主题独立的 localStorage 键中。减少动态效果偏好默认暂停，点击播放可主动启用。

从项目根目录运行 `npm run build:blue-sky`，会生成可独立双击打开的 `dist/blue-sky-train/index.html` 和 Wallpaper Engine 配置。

## 程序化 TA 实验
- [设计文档](docs/设计文档.md)

[打开 HTML 设计方案](lab/index.html)。本轮先建立统一时间与坐标，验证云的形与光、列车轮轴和世界空间蒸汽、同场景水面反射，再在组合样片中观察运动关系。

- [单独的云](lab/examples/cloud.html)：可逐层显示白底、浅蓝、中蓝和完整四层平涂，或查看遮罩。
- [列车与蒸汽](lab/examples/train.html)：放大观察车轮与连杆，支持速度和风速调节。
- [水面反射](lab/examples/water.html)：支持固定镜头和关闭水波检查倒影。
- [组合样片](lab/examples/scene.html)：云、山、车、桥、烟、水与近景的共同运动。

每个案例包含自己的全部 GLSL、JavaScript 和样式，可以单独保存并离线运行。核心模块在 `lab/src/`；生成命令为 `npm run build:ta`，浏览器检查为 `npm run test:ta`。方案页可直接查看和复制各模块源码。

这轮交付用于 TA 设计与最小实现验证。正式 SVG 壁纸入口没有切换；目标图级造型、颜色空间、无限循环和正式宿主接入按方案中的 R02–R05 继续推进。

## R03 扁平云纹与像素对比

[打开逐像素对比](lab/cloud-compare.html)：原图与 R01 / R02 / R03 使用 2048×768、t=0 的原始像素，支持叠加、差分、轮廓、25×25 放大和 RGB 取样。R01 / R02 是纯程序几何；R03 从已有参考 SVG 整理 1,363 条有序路径，启动时生成四层嵌套遮罩，再由 Shader 平涂和驱动运动。

从白色底形开始，依次加入浅蓝、中蓝、深蓝内层；颜色在层内保持平坦。各层共享采样坐标，蓝层不会漂出白底。遮罩纹理为 2048×480 RGBA8，原始数据 3.75 MiB；PNG 不参与运行时绘制。参考轮廓与全部代码内嵌在独立 HTML 中。

运行 `npm run compare:cloud` 重新捕获三版云层并记录误差；之后运行 `npm run build:ta` 更新方案统计。`build:ta` 会先执行 `tools/build-cloud-patterns.mjs` 生成 `assets/blue-sky-train/vector/cloud-patterns.json`。历史版本分别保存在 `lab/history/r01/` 和 `lab/history/r02/`。

当前使用颜色阈值与原图遮挡线提取云区，山后与画幅外的区域没有重建，适合构图内的小幅运动。R03 轮廓误差降低来自参考数据复用，不代表纯程序几何生成能力提升。

## R04 完整云素材复用

[打开持续移动演示](lab/cloud-library.html)。本轮采用完整云簇素材：两张 1536×1024 透明 PNG 由内置 image_gen 参考原图画风重新绘制，原图只作为风格参考。每张云都有完整轮廓与透明外边距；程序按整张图片取样，并保持宽高比及统一受光方向。

原件和完整提示词记录放在 `assets/blue-sky-train/clouds/r04/`（相对项目根目录）。`lab/src/asset-cloud.glsl` 合成云层，`asset-stream.js` 按世界距离与种子排列云簇，`asset-runtime.js` 驱动移动、暂停、预览倍速和纹理加载。近远层各保留 6 个槽位，出屏后更新位置和组合；两张 RGBA8 纹理原始数据共 12 MiB，不随行进增加。水面通过同一场景求值获得倒影。

运行 `npm run build:cloud-library` 生成素材和代码全部内嵌的独立 HTML；运行 `npm run test:cloud-library` 验证透明边缘、8 个续接边界、确定性、调速、实际加速播放和窄屏。报告与截图位于 `lab/evidence/r04-assets/`。24 小时检查使用时间跳转，未连续运行 24 小时，未验证 4K 或 Wallpaper Engine 新入口。

目前只有两种云形，局部纹样会重复。后续可扩充高塔、横带、碎云等完整原件，在统一色板与光照下增加构图变化；本轮不宣称每朵云的图案由程序重新生成。正式 SVG 壁纸入口仍按原方式运行。R03 的源码和截图已另存于 `lab/history/r03/`，原像素比较仅评价 R03 固定构图，不用于衡量 R04 随机排列的画面。

## R05 远景尺度

[同画幅查看原图、R04 与当前远景](lab/cloud-library.html)。按原图校准列车在画面中的占比：宽度约 15%，最高轮廓约为画面高度的 3.6%。桥面位于从上向下 62.4% 处，水线位于 73.5% 处；桥柱底部高于水线，保留岸线空间。桥拱节距从 0.205 降到 0.112（以图高为单位）。这些数值用于构图校准，不代表真实世界的长度。

新场景模块为 `lab/src/scene-common.glsl`、`scene-train.glsl`、`scene-world.glsl`。机车形状复用原 `train.glsl`，用统一的场景位置缩放车身、轮组及烟囱出生点；倒影仍调用同一场景。远山使用偏蓝、低对比的层次，近岸与前景提高浓度，云的排列增加高低间隔。行进速度与视差随远景尺度减慢，云仍可持续续接。

页面可切换「当前远景」「调整前 R04」「原图参考」，并显示桥面、水线和列车范围标尺。原图和 R04 为内嵌静态对照，当前远景是实时画面；完整 HTML 继续支持离线打开。R04 源码、输出和截图保存在 `lab/history/r04-assets/`，本轮证据在 `lab/evidence/r05-composition/`。构建和验证命令仍为 `build:cloud-library`、`test:cloud-library`。

本轮解决远眺的比例与层次，山体、植被和桥梁笔触仍与原画不同；两张云素材也仍会形成可辨认的重复。

## R06 蓝灰石桥

[查看石桥与局部放大对照](lab/cloud-library.html)。桥的材质与结构独立到 `lab/src/scene-bridge.glsl`：冷蓝灰正面、深蓝侧面、梁底暗线、圆角拱肩、墩顶分层石帽和微扩的墩脚。石面只有低对比的斑块、断续砌缝与细粒度色差；纹样绑定世界坐标，随桥移动。墩脚加入苔色，以衔接远岸草丛。云、列车尺度和桥的节距沿用 R05。

画质 1× 时按原图的 2048×768 渲染，窗口缩小时缩放展示，避免栏杆细线在较小的绘制缓冲中丢失。展开的桥梁细节区将原图与实际场景的同一画幅区域放大；原图为静态，当前画面以最多约 6.7 次/秒刷新局部，暂停时立即更新。可折叠该区停止额外的局部绘制。

本轮全景对照中的「调整前」改为 R05。R05 已归档在 `lab/history/r05-composition/`，R06 的浏览器报告、全景和桥梁局部证据位于 `lab/evidence/r06-bridge/`。运行命令仍为 `npm run build:cloud-library` 与 `npm run test:cloud-library`。这是按原图结构与色彩重建的程序石桥，局部石纹并非逐像素复刻。

## R07 日光与冷暖层次

[查看光感与局部对照](lab/cloud-library.html)。`scene-bridge.glsl` 将左上方日光落在桥墩左侧石棱、桥面顶边和墩脚；用石帽位置截断亮边，保留冷蓝侧面及梁底。接近地面的正面增加少量绿色反光。所有细节仍使用世界坐标，随桥移动。

`scene-world.glsl` 提亮远岸草丛的朝上部分，并给山谷低处增加天蓝空气透视。湖面仍调用同一场景函数，因此受光草地、桥墩与山谷颜色自动进入倒影。日光属于手绘风的颜色分层与简化遮光，不使用物理光线追踪。云原件的既有光色保持原样。

日光滑杆对应 `uSun`（0–1，默认 1）。暂停后可以在同一帧比较：0 为 R06 原有光色，1 为本轮光感。列车尺度、桥梁轮廓和云布局保持原样。R06 源码、输出、工具和证据已保存在 `lab/history/r06-bridge/`；本轮浏览器报告与同帧开关日光的局部图片位于 `lab/evidence/r07-lighting/`。

## R08 近景草叶与行进视差

[查看近景掠过](lab/cloud-library.html)。按用户最新优先级，先实现草簇与枝叶从眼前经过。`scene-foreground.glsl` 替换原来固定于屏幕两侧的树丛：所有根部位置、轮廓、叶片颜色均在世界坐标下计算，完整植株横向进入和离开画面。枝叶留有空隙，短暂遮住桥或列车；两层弯曲草叶位于画面下缘。

以桥的基准平移为 1，近岸坡为 0.72、后排草为 2.5、枝叶为 3.2、眼前草为 5.2；既有远山为 0.035–0.125。`uGroundTravel` 由运行时对前进速度积分，暂停调速不会改变近景位置，前进设为 0 后根部停下；风速独立控制植株的弯曲摆动。查看菜单增加「单看近景草叶」。

R07 已归档在 `lab/history/r07-lighting/`。R08 证据位于 `lab/evidence/r08-foreground/`：实际像素匹配、持续播放、离屏续接、不同时间截图及短片。远山轮廓与沟壑材质仍保留上一版，需在此近景样板之后另行调整。当前仍为 TA HTML 实验入口。

## R09 生成近景素材

[查看生成素材进入场景](lab/cloud-library.html)。按用户要求，近景草、枝叶和下缘灌木改用内置 imagegen 生成的透明 PNG。参考原图的小叶簇、深蓝绿暗部和左上方黄绿受光；草丛与低灌木经过一次生成编辑清理透明边缘。原件、初稿及完整提示词记录存放在项目根目录的 `assets/blue-sky-train/foliage/r09/`，实际加载 `grass.png`、`leaves.png`、`understory.png`。

`scene-foreground.glsl` 现在只采样原件、合成透明度、排列与弯曲 UV，不再计算叶片或草叶的图形和颜色。素材保留自身宽高比和光照方向，不做镜像；根部随前进平移，风摆随距根部的高度逐渐增强。前进速度积分与 R08 的远近速度倍率继续使用。五张云与近景 RGBA8 纹理原始数据合计 31,455,888 字节（约 30 MiB），复用期间不追加纹理。

查看菜单新增三个完整近景素材模式，页面同时提供透明原件预览和下载。桥梁局部对照默认折叠，展开后继续实时更新。近景的既有受光不随日光滑杆改变。当前每类近景各一张原件，重复图案仍可能被认出。

R08 已归档到 `lab/history/r08-foreground/`。R09 证据保存于 `lab/evidence/r09-generated-foreground/`，包括透明边界、实际像素位移匹配、离屏衔接、停止前进后的风摆、离线加载、全景截图与真实播放短片。运行 `npm run build:cloud-library` 构建，`npm run test:cloud-library` 验证。远山的美术修改仍待后续处理；正式 SVG 壁纸入口未切换。
