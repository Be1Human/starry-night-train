# 星河夜行列车

本目录保留完整单文件 WebGL 主题。双击 index.html，或通过本地服务打开。H 隐藏/显示参数面板，空格暂停/继续。星空、云、桥、列车、蒸汽和水面均由 Shader 计算。

本精简版保留原始视觉运行入口；录像、教学影片、旧实验和音频导出不属于该 HTML 的依赖。蓝天专用验收脚本不能代表星空已完成全部专项或原生 Wallpaper Engine 验收。

## 来源与许可

- 改编自 [incarnation-gem/sunset-cloud-train](https://github.com/incarnation-gem/sunset-cloud-train)，该项目提取自 [Rice-dog/code-codex](https://github.com/Rice-dog/code-codex) 的 Cloud Train Background 插件（MIT）。面板交互和渲染循环思路参考原版。
- 云的噪声、fbm、12 层高度场与色带合成移植自 mdb shader。该 Shader 未附独立再分发许可，沿用原声明：仅供学习与欣赏，请勿商用；如权利人认为不妥，联系维护者后处理。
- 夜空、石拱桥、列车、蒸汽、水面、近景与远岸为项目中的重写实现。
