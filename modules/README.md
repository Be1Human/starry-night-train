# 图层方法库

从 [可视化目录](../library/index.html) 选效果，进入各方法目录查看源码与 README。

- canonical：蓝天权威源，编辑这里，然后 npm run build:library。
- generated-extract：星河教学提取，编辑其 sourceOrigins 中的原主题，再重建。
- mixed：同目录有权威适配文件与生成提取文件，按 sourceAuthority / editInstructions 分别编辑。
- archived-extract：历史版本或 SVG 原画动画的冻结教学提取。另建模板演进，保留原实验。

source-map.json 管理蓝天兼容镜像；_shared/ 管理公共函数。预览有单元素与整景关系两种形式，名称不能替代真实依赖检查。

所有接口约定、适用边界、素材与来源以每个 template.json / README.md 为准。新增模板请先遵循 [拆图流程](../docs/module-workflow.md)。
