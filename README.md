# 沿途 · AI Train Gallery

完整火车壁纸与分类素材。当前包含 2 张完整壁纸、8 项精选素材。纯 Shader、素材与 Shader 混合实现均可复用。

[打开 Gallery](https://be1human.github.io/starry-night-train/library/) · [分类素材](https://be1human.github.io/starry-night-train/library/#materials)

## 使用

选择素材 → 使用与源码 → 复制 AI 使用说明。源码、透明 PNG、依赖与案例配方均保留在对应目录。

本分支是 train-wallpapers 的静态发布快照。Node.js 22+ 下运行 npm start 可本地浏览；修改权威源码后运行 npm run build:library 重建预览。无需 npm install。

[星河主题的来源与使用范围](themes/starry-night-train/README.md#来源与许可)。生成素材的记录保存在 assets/；提取源码不改变原有授权。
